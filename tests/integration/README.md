# 통합 테스트

루트에서 runtime/.venv/Scripts/python.exe -X utf8 -m pytest -q를 실행합니다. 기존 VLM과 새 계약·추적·후보·영상·판단·전체 실행을 함께 검증합니다.

모델 없는 테스트는 합성 관측과 통제된 VLM 응답을 사용합니다. MP4 인코딩/디코딩·VFR PTS·ROI·입력 기록·큐·완료/종료는 실제 구현을 통과합니다. 느린 검증 중 지속 탐지, 반복 행동 구분, 오류와 불확실의 분리를 검사합니다. 테스트 통과는 실모델 정확도 평가가 아닙니다.

실제 모델 점검과 미검증 범위는 docs/testing.md를 참고합니다.
