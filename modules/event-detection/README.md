# 이벤트 탐지

YOLO·MediaPipe Tasks 실모델 어댑터와 E01/E02/E03 후보 상태 머신을 구현했습니다. models extra가 실제 모델 의존성입니다.

객체/사람 모델을 따로 지정할 수 있습니다. 얼굴·손·포즈를 추출해 대상 crop 좌표를 원본으로 변환하고 포즈 손목에 연결된 손을 사용합니다. 객체 추적은 클래스·IoU·시간 연속성을 사용하며 모호한 연결에는 새 ID를 발급합니다.

손–물체 거리, 손–입 거리·접근 속도, 용기–입 거리를 사용합니다. 약이 없어도 E02를 생성하며 E02/E03가 함께 존재할 수 있습니다. 후보 갱신은 revision 증가, 이탈 후 새 행동은 새 ID입니다. 탐지를 이벤트 확인으로 취급하지 않습니다.

초기값은 평가로 조정해야 합니다. 기본 YOLO11n에는 약·포장 클래스가 없어 E01 평가에는 사용자 학습 가중치·class_map이 필요합니다. 실모델 점검은 scripts/smoke_real_detection.py를 사용합니다.
