# 세션 최종 판단

SessionDecision은 VerificationResult와 고정 요청의 연결을 확인하고 현재 수신한 결과만 누적합니다. 같은 요청의 중복을 제외하고 내용 충돌은 거부합니다.

E02의 약 식별·입 전달이 확인되고 대상이 일치하며 같은 물체·행동의 상충이 없으면 COMPLETE를 한 번 생성합니다. E01/E03는 선택적 보조입니다. 오류·미실행·기각·불확실·EOF를 최종 미완료로 바꾸지 않습니다.

같은 후보 또는 동일 물체의 겹치는 행동이 상충 범위입니다. 명시적 비약물 설명은 설정 가능한 패턴으로 검사하며 모든 자연어 의미 충돌을 보장하지 않습니다. 설정·수신·평가·완료 기록을 저장합니다.
