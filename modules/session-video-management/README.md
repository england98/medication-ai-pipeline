# 세션·영상 관리

SessionManager는 인증 사용자·예정 회차·원본 시간 원점을 연결하고 같은 대상의 완료 통지로만 세션을 종료합니다.

VideoManager는 디스크 JPEG 순환 버퍼, 활성 후보 구간 보존, 후행 영상 대기, 실제 PTS MP4·ROI를 구성합니다. 요청/실제 범위를 구분하며 없는 프레임을 채우지 않습니다. 검증·근거 클립은 보존하고 참조가 끝난 임시 프레임만 해제합니다. 디스크 한도 초과는 명시적 오류입니다.

read_video는 파일/명시적 FFmpeg 캡처 입력을 받습니다. PTS 부재·역행·밀리초 중복과 세션 내 해상도 변경은 오류로 처리합니다. 가변 시각·홀수 해상도·ROI 매핑·임시 파일 해제를 통합 테스트합니다.

`InputRecorder`는 후보 생성 여부와 독립적으로 전달받은 프레임 전체를 `recording/input.mp4`에 저장합니다. 원본 PTS를 첫 수신 프레임 기준으로 정규화하고, `frames.jsonl`에 녹화 프레임과 원본 FrameRef를 연결합니다. H.264/yuv420p로 재인코딩하며 홀수 해상도는 우측·하단만 패딩합니다. 음성은 포함하지 않습니다.

`close()`는 인코더를 비우고 MP4를 닫은 뒤 `metadata.json`에 상태·종료 사유·프레임 수를 남깁니다. 런타임은 정상 종료와 인터럽트·오류 시에도 이를 호출하며, 녹화 파일 마감과 후보 검증 마감은 별도로 처리합니다. 전체 녹화 파일에는 후보 JPEG 버퍼의 `max_spool_bytes` 제한이 적용되지 않습니다. 설정·재생 방법은 [웹캠 테스트 절차](../../docs/webcam-testing.md)를 참고합니다. PTS와 time_base 처리 기준은 [PyAV 시간 문서](https://pyav.org/docs/stable/api/time.html)를 참고합니다.
